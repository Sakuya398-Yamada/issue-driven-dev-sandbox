# issue-driven-dev-sandbox

[issue-driven-dev-starter](https://github.com/Sakuya398-Yamada/issue-driven-dev-starter) の定期ルーティン（`daily-triage`・`weekly`・`weekday-issue-start`）を確かめるための検証用リポジトリです。

## 入っているもの

issue-driven-dev-starter の `template/` の中身だけです。

- [`CLAUDE.md`](CLAUDE.md)
- [`.claude/`](.claude/)

アプリのコードはありません。
